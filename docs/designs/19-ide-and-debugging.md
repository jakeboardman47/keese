# 19 — IDE and Debugging

## Decision

GoLand (primary) and VSCode (secondary) developer workflows for two flows:
(a) remote dlv attach to the keese operator in kind, and (b) ACP session
attach to a live agent runtime via `kubectl-keese attach`. IDE configs live
in `dev/ide/goland/` and `dev/ide/vscode/`; both are committed and
generated by `make ide-config`.

## Flow A — dlv attach to the operator

**Build:** Tilt's `ko_build` for the operator includes a `debug` Tiltfile
resource triggered by `KEESE_DEBUG=1 tilt up`. That resource builds with
`-gcflags='all=-N -l'` and sets `KO_FLAGS=--debug` so the binary is
unoptimised.

**Pod security:** The debug Deployment patch (`dev/ide/debug-operator-patch.yaml`)
adds `securityContext.capabilities.add: [SYS_PTRACE]` to the operator
container. `privileged: true` is NOT added (rule 05.11). This patch is
Kustomize-overlaid and never reaches non-dev clusters.

**dlv:** The debug image runs `dlv exec --headless --listen=:2345
--api-version=2 -- /manager` as PID 1, honouring SIGTERM (rule 06.1) with
a 30 s drain budget before exit.

**Port-forward:** `make dlv-attach` runs:
`kubectl port-forward -n keese-system deploy/keese-operator 2345:2345`.

**GoLand config** (`dev/ide/goland/run/dlv-operator.run.xml`): Go Remote
configuration, host `localhost`, port `2345`, source root `$PROJECT_DIR`.

**VSCode config** (`dev/ide/vscode/launch.json`): mode `remote`, host
`localhost`, port `2345`, `substitutePath` maps the in-container
`/ko-app/manager` source root to `${workspaceFolder}`.

Both configs are idempotent templates. `make ide-config` writes them only
if absent, so local overrides persist across runs.

## Flow B — ACP attach to agent sessions

**Auth:** Developer runs `keesectl auth login` (D28 OIDCProvider) to obtain
a short-lived OIDC JWT. The JWT is stored in `~/.keese/credentials.json`
and picked up by `kubectl-keese attach`. Token TTL ≤ 10 m (rule 05.3);
`kubectl-keese` auto-refreshes before expiry.

**Attach:** `kubectl-keese attach <workspace>` creates or reuses a
`WorkspaceSession` CR (D27, design 08b) with `sessionName: default`. The
bridge sidecar (08b) multiplexes ACP frames over `kubectl exec` — no open
ports, no NetworkPolicy change.

**Named + multi-session:** `--session=<name>` selects a named session. Mode
`per-user` (08b §Session modes) allows multiple concurrent named sessions.
The developer picks a session via:

| Intent | Command |
|---|---|
| Start or reuse default | `kubectl-keese attach <workspace>` |
| Named new session | `kubectl-keese attach <workspace> --session=work-2` |
| List my sessions | `kubectl-keese sessions list <workspace>` |
| Terminate a session | `kubectl-keese sessions delete <workspace> --session=work-2` |

**GoLand ACP:** GoLand's native ACP plugin (JetBrains AI toolchain) is
configured to target `keese-attach:///<workspace>` — a custom URI scheme
registered by the `keese-jetbrains` plugin (bundled under
`dev/ide/goland/plugins/`). The plugin shells out to `kubectl-keese attach`.

**VSCode ACP:** `block.vscode-goose` extension reads workspace config from
`.vscode/settings.json` key `keese.acpWorkspace`. `make ide-config` writes
this key. The extension also shells out to `kubectl-keese attach`.

## Flow C — Step-debug agent recipes (Python extensions)

Goose extensions run as Python subprocesses within the agent container.
Goose's `--debug` flag enables verbose MCP-frame logging. For dlv-style
breakpoints in Python: `debugpy` is pre-installed in the debug agent image;
`KEESE_DEBUGPY_PORT=5678` env var (set by the debug Tiltfile resource)
causes goose to start `debugpy.listen(5678)` before executing the extension.
A second `make port-forward-debugpy` targets `5678:5678`. GoLand and VSCode
both include a "Python Remote (debugpy)" configuration in `dev/ide/`.

## Failure modes

| Failure | Mitigation |
|---|---|
| dlv connection refused | Check `make dlv-attach` port-forward is running; verify debug image built (`KEESE_DEBUG=1`) |
| ACP version mismatch | Bridge returns `UNSUPPORTED_VERSION` (08b); upgrade `kubectl-keese` to match bridge semver |
| OIDC token expired mid-session | `kubectl-keese attach` detects 401 from attach webhook; re-runs `keesectl auth login`; reconnects within 08b `attachGrace` window |
| Concurrent attach same session | `mode=per-user` increments `attachedClientCount`; both clients share turn stream; contention visible in `keese_acp_attach_total` metric |
| NetworkPolicy blocks dlv | Debug patch explicitly adds egress from `dev` namespace to `keese-system` on 2345/TCP; rule 05.5 exemption documented here as break-glass (lab only) |
| Multi-developer conflict | `maxConcurrentAttaches` (08b §Three-layer auth) limits concurrent attaches; excess clients receive `403 AttachLimitExceeded` |

## Observability

dlv attach: no runtime metrics (debug-only). ACP attach: inherits 08b spans
(`keese.acp.attach`, `keese.acp.reconnect`) and metrics
(`keese_acp_attach_total{result,workspace,mode}`). debugpy: no dedicated
metrics; goose `--debug` logs to structured OTEL log pipeline (10a).

## IDE config files (summary)

`dev/ide/` is created by `make ide-config`. Contents:

- `goland/run/dlv-operator.run.xml` — Go Remote run config
- `goland/run/debugpy-agent.run.xml` — Python Remote (debugpy) run config
- `goland/plugins/` — keese-jetbrains plugin source (ACP URI scheme)
- `vscode/launch.json` — Go Remote + Python Remote launch configs
- `vscode/settings.json` — `keese.acpWorkspace` default stub
- `debug-operator-patch.yaml` — Kustomize patch adding `SYS_PTRACE`

`make ide-config` is idempotent; existing files are not overwritten.
